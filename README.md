# Salesforce Login Handler

Salesforce-side (and related) code for login handling. Repository initialized for greenfield work.

## Local setup

1. Open this folder in your editor (or add it to a multi-root workspace).
2. Authenticate to a dev org or scratch org with the Salesforce CLI (`sf org login web` or your usual flow).
3. Deploy or push metadata from `force-app` as the project grows.

## Project shape

This repo uses Salesforce DX layout: `sfdx-project.json` and `force-app/main/default` for metadata.
